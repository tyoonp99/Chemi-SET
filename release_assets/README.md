# Release assets

This folder contains files used for Google Play registration and portfolio presentation. They are intentionally kept outside `assets/`, because the game does not load them at runtime.

- `google_play/play_store_icon_512.png`: Google Play app icon
- `google_play/play_store_feature_graphic_1024x500.png`: Google Play feature graphic
- `google_play/screenshots/`: cropped 9:16 store screenshots
- `google_play/source/`: editable source image; do not upload this file directly

Installable APK/AAB archives are stored locally in `release_builds/` and are excluded from Git.
