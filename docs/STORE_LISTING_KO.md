# CHEMI-SET Google Play 스토어 등록 초안

> 최종 수정: 2026-08-10

## 앱 이름

CHEMI-SET

## 짧은 설명

세 장의 실험 카드를 조합해 합성을 찾는 빠르고 정교한 관찰 퍼즐

## 상세 설명

모양, 색상, 내용물 상태를 비교해 합성이 되는 카드 세 장을 찾아보세요.

각 속성은 세 카드에서 모두 같거나 모두 달라야 합니다. 단순한 규칙이지만 여러 조합이 겹치면 빠른 관찰과 정확한 판단이 필요합니다.

- 급속 실험: 제한 시간 1분 동안 빠르게 합성을 찾아 최고 점수에 도전합니다.
- 정밀 실험: 보드의 모든 합성을 찾고 정확한 순간에 완료를 선언합니다.
- 자유 실험: 시간과 점수 부담 없이 힌트를 활용하며 합성 규칙을 익힙니다.

모든 기록은 기기에 저장되며 인터넷 연결 없이 플레이할 수 있습니다.

## Play Console 입력 메모

- 앱 또는 게임: 게임
- 카테고리: 퍼즐
- 광고 포함: 아니요
- 앱 내 구매: 없음
- 인터넷 연결: 필요 없음
- 데이터 수집·공유: 없음. 로컬 게임 기록만 저장
- 앱 접근 제한: 없음
- 개인정보처리방침: `docs/PRIVACY_POLICY.md`를 공개 URL로 게시한 뒤 입력
- 대상 연령: 실제 의도에 맞춰 선택. 아동 연령을 포함하면 Families 정책을 별도 검토
- 콘텐츠 등급: Play Console IARC 설문 완료 필요

## 필요한 이미지

- 앱 아이콘
- 휴대전화 스크린샷: 타이틀, 급속 실험, 정밀 실험, 자유 실험, 결과 화면 권장
- 그래픽 이미지: Play Console이 요청하는 최신 규격에 맞춰 제작
