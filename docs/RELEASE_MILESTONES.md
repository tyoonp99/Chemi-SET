# CHEMI-SET 출시 마일스톤

> 문서 버전: 1.3  
> 최종 수정: 2026-08-08  
> 현재 단계: M3-2 효과음

본 문서는 CHEMI-SET의 현재 개발 상태부터 첫 출시까지 필요한 작업과 완료 기준을 정의합니다. 새로운 기능을 추가할 때는 현재 마일스톤의 출시 필수 작업을 우선합니다.

---

## M0. 규칙·밸런스 동결

**목표:** 출시 전까지 흔들리지 않을 핵심 규칙을 확정합니다.

- [x] 급속 실험 점수 체계 확정
  - 남은 합성 1개: 300점 / EXCELLENT
  - 남은 합성 2개: 240점 / GREAT
  - 남은 합성 3~4개: 120점 / GOOD
  - 남은 합성 5개 이상: 80점 / GOOD
- [x] 정밀 실험 점수 확정
  - 합성 성공: +100점
  - 합성 중복·실패: -75점
  - 완료 성공: +400점
  - 완료 실패: -200점
- [x] 자유 실험의 힌트·누적 합성·완료 규칙 확정
- [x] 플레이 로그를 통한 기준 데이터 확보
- [x] 점수 규칙 버전과 실제 설정값 최종 대조
- [x] 확정된 규칙을 관련 문서에 반영

**완료 기준:** 세 모드의 규칙을 문서로 설명할 수 있고, 코드와 UI가 동일한 값을 사용합니다.

---

## M1. 핵심 게임 루프 마감

**목표:** 시작부터 결과와 재도전까지 끊기지 않게 만듭니다.

- [x] 정밀 실험에 현재 보드에서 찾은 합성 기록 표시
- [x] 공통 결과 팝업에 급속·정밀 실험별 결과 내용 구성
- [x] 급속 실험 결과에 다음 기록 표시
  - 최종 점수
  - 최고 콤보
  - EXCELLENT·GREAT·GOOD·오답 횟수
  - TOP 5 진입 순위
- [x] 정밀 실험 결과에 다음 기록 표시
  - 성공한 합성
  - 합성 실패·중복
  - 완료 성공·실패
  - 최종 점수
- [x] `다시 하기`와 `타이틀로` 동선 정리
- [x] 신기록 저장과 모드별 랭킹 반영 재검증

**완료 기준:** 어떤 모드든 시작 → 플레이 → 결과 → 재시작을 막힘 없이 반복할 수 있습니다.

---

## M2. 게임 방법과 첫 실행 튜토리얼

**목표:** 외부 설명 없이도 처음 플레이할 수 있게 만듭니다.

- [x] 타이틀에 `게임 방법` 메뉴 추가
- [x] 합성이 되는 조합 2개와 합성이 안 되는 조합 예시 제공
- [x] 합성 판정 원리 설명
- [x] 완료 조건과 점수 설명
- [x] 급속 실험의 남은 합성 개수별 점수 설명
- [x] 자유 실험의 힌트와 누적 기록 규칙 설명
- [x] 첫 실행 시 한 번만 튜토리얼 표시
- [x] 게임 방법 화면에서 인터랙티브 튜토리얼 다시 보기 제공
- [x] `카드 선택 → 합성 → 완료`를 직접 체험하도록 구성

**완료 기준:** 처음 보는 플레이어가 외부 도움 없이 첫 합성과 첫 완료를 성공할 수 있습니다.

---

## M3. 조작감·시청각 피드백

**목표:** 소리가 없어도 선택·합성·완료 결과가 명확하고, 소리와 진동을 켜면 손맛이 강화되게 만듭니다.

### M3-1. 시각 피드백 정리

- [x] 급속 실험 점수 롤링 적용
- [x] 판정·점수·콤보 플로팅 피드백 적용
- [x] 오답 HUD 흔들림 적용
- [x] 자유 실험 힌트 카드와 완료 버튼 펄스 적용
- [x] 카드의 중앙 피벗과 기본 위치·스케일을 모드별로 통일
- [x] 카드 선택 시 짧은 눌림 효과와 선택 상태 강조 적용
- [x] 카드 선택 해제 시 원래 상태로 정확히 복귀
- [x] 빠른 연타 중 기존 Tween을 종료하고 위치·스케일을 복구하는 처리 적용
- [x] 공통 버튼은 추가 스케일 애니메이션 없이 기존 눌림 스타일을 유지하기로 결정
- [x] 합성·완료 성공·실패는 현재 점수·판정 피드백으로 명확하다고 확인

**범위 결정:** 선택 카드 3장 플래시, 오답 카드 흔들림, 완료 보드 전환 같은 큰 카드 연출은 현재의 담백함과 급속 실험의 속도를 해칠 수 있어 출시 범위에서 제외합니다.

### M3-2. 효과음

- [ ] 선택·해제·버튼·합성·완료 효과음 확보 및 라이선스 기록
- [x] `Master`와 `SFX` 오디오 버스 구성
- [x] 카드 선택·해제 효과음 적용
- [x] 합성 성공·실패 효과음 적용
- [x] 완료 성공·실패 전용 효과음 적용
- [x] 빠른 연타 시 동일 효과음이 과도하게 겹치지 않도록 제한
- [ ] 설정 화면에 사운드 ON/OFF 제공
- [ ] 사운드 설정 저장 및 재실행 복구

### M3-3. 모바일 진동

- [ ] 데스크톱 실행에 영향을 주지 않는 공통 진동 호출 함수 구성
- [ ] 합성 성공은 짧게, 실패는 짧게 두 번 적용
- [ ] 완료 성공은 합성 성공보다 조금 강하게 적용
- [ ] 설정 화면에 진동 ON/OFF 제공
- [ ] 진동 설정 저장 및 재실행 복구
- [ ] 실제 Android 기기에서 강도와 반복 피로도 조정

**완료 기준:** 화면만 봐도 입력과 판정을 구분할 수 있고, 효과음·진동을 켰을 때 과하거나 지연되는 피드백 없이 조작감이 좋아집니다.

---

## M4. 입력·앱 수명주기·저장 안정성

**목표:** 연타·시간 종료·앱 전환처럼 충돌하기 쉬운 상황에서도 게임 상태가 망가지지 않게 만듭니다.

- [ ] 합성·완료 판정 중 추가 입력을 막는 세션 입력 잠금 정리
- [ ] 빠른 연타와 다중 터치로 카드 선택 수가 어긋나지 않는지 검증
- [ ] 타이머 종료와 합성·완료 입력이 동시에 발생하는 경우 검증
- [ ] 팝업 표시 중 보드와 HUD 입력 차단
- [ ] 앱이 백그라운드로 갈 때 시간 모드 자동 일시정지
- [ ] 앱 복귀 시 타이머·팝업·선택 카드 상태 복구
- [ ] Android 뒤로가기 동작 정의
  - 플레이 중: 일시정지 또는 종료 확인
  - 팝업 표시 중: 최상단 팝업 닫기
  - 타이틀: 종료 확인
- [ ] 랭킹·자유 실험 누적·튜토리얼 완료 상태 저장 재검증
- [ ] 손상되거나 일부 키가 없는 저장 파일 복구 검증
- [ ] 저장 도중 앱이 종료돼도 기존 데이터가 최대한 유지되도록 방어
- [ ] Godot 오류·경고·누락 리소스·깨진 경로 제거

**완료 기준:** 각 모드에서 연타, 시간 종료, 백그라운드 전환, 강제 종료를 반복해도 크래시나 상태 꼬임이 발생하지 않습니다.

---

## M5. 기기 UI·성능·출시 자료

**목표:** 여러 기기에서 읽고 누를 수 있으며, 스토어에 제출할 자료와 빌드를 준비합니다.

### M5-1. 기기 UI와 성능

- [ ] Safe Area 대응
- [ ] 16:9·19.5:9·20:9 화면 비율 확인
- [ ] 작은 휴대폰과 태블릿에서 팝업·튜토리얼·결과 화면 확인
- [ ] 주요 버튼의 터치 영역이 최소 48dp 수준인지 확인
- [ ] 최소 폰트 크기와 한국어 줄바꿈·말줄임 확인
- [ ] 저사양 Android 기기에서 Tween·파티클·오디오 성능 확인
- [ ] 한 세션을 오래 실행해도 임시 UI와 Tween 노드가 누적되지 않는지 확인

### M5-2. 패키지와 스토어 자료

- [ ] 앱 이름과 패키지명 확정
- [ ] 버전 번호와 버전 코드 설정
- [ ] 앱 아이콘과 스플래시 화면 준비
- [ ] Pretendard 및 사용 에셋·효과음 라이선스 정리
- [ ] 개인정보 처리 방향 작성
- [ ] 플레이 로그의 출시 빌드 사용 여부 결정
- [ ] 스토어 소개문과 스크린샷 준비
- [ ] Android 릴리스 Export Preset 점검
- [ ] 서명 키 생성 및 안전한 위치에 보관
- [ ] 실제 기기에 릴리스 빌드 설치

**완료 기준:** 지원 화면 비율에서 UI가 잘리지 않고, 실제 기기에 설치 가능한 서명 빌드와 스토어 자료가 준비됩니다.

---

## M6. 출시 후보 검증과 동결

**목표:** 출시 후보 빌드를 고정하고 회귀 버그와 데이터 손실 가능성을 제거합니다.

- [ ] 점수·보드 생성·튜토리얼 문구·저장 형식 동결
- [ ] 새 기기에 클린 설치 후 첫 실행 튜토리얼 확인
- [ ] 이전 테스트 버전 위에 업데이트 설치
- [ ] 급속 실험 5판 이상 완료
- [ ] 정밀 실험 5판 이상 완료
- [ ] 자유 실험 힌트·누적 기록·재실행 검증
- [ ] 일시정지·설정·랭킹·결과·재시작 전체 동선 확인
- [ ] 사운드·진동 설정을 변경한 뒤 재실행 복구 확인
- [ ] 백그라운드 전환과 Android 뒤로가기를 각 화면에서 확인
- [ ] 10회 이상 연속 세션에서 크래시·입력 잠김 없음
- [ ] 손상 저장 파일과 이전 형식 저장 파일 복구 확인
- [ ] 출시 빌드에서 디버그 UI와 불필요한 플레이 로그 제거
- [ ] 치명적·높은 우선순위 버그 0개 확인
- [ ] 최종 버전 태그와 소스·서명 정보 백업 생성

**완료 기준:** 동일한 출시 후보 빌드로 핵심 동선을 반복해도 치명적 버그가 없고, 저장 데이터가 재실행과 업데이트 후에도 유지됩니다.

---

## 출시 후 검토 항목

아래 기능은 첫 출시를 막는 필수 요소가 아니므로 출시 이후 데이터와 사용자 반응을 보고 결정합니다.

- 정교한 쉬움·표준·어려움 보드 프로필
- 합성 유형별 난이도 보너스
- 일일 도전
- 업적·레벨·재화
- 온라인 랭킹
- 추가 게임 모드
- 계정 및 클라우드 저장
- 선택 카드 성공·실패·완료의 대형 시각 연출

---

## 진행 순서

`M0 동결 → M1 게임 루프 → M2 튜토리얼 → M3-1 시각 피드백 → M3-2 효과음 → M3-3 진동 → M4 안정성 → M5 기기·출시 준비 → M6 출시 후보`

각 마일스톤을 완료할 때 체크박스와 현재 단계를 함께 갱신합니다.
