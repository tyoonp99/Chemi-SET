# CHEMI-SET 에셋 및 라이선스 기록

> 최종 확인: 2026-08-10

출시 빌드에 포함되는 외부 에셋의 출처와 배포 조건을 기록한다. 출처가 확인되지 않은 에셋은 출시 전에 증빙을 추가하거나 교체한다.

## Pretendard

- 사용 파일: `Pretendard-Medium.ttf`, `Pretendard-SemiBold.ttf`, `Pretendard-Bold.ttf`, `Pretendard-ExtraBold.ttf`
- 저작권: Copyright (c) 2021, Kil Hyung-jin
- 라이선스: SIL Open Font License 1.1
- 공식 출처: https://github.com/orioncactus/pretendard
- 라이선스 전문: `assets/fonts/OFL-1.1.txt`
- 상태: 확인 완료

폰트 라이선스 전문은 Android 내보내기 결과물에 포함되도록 `export_presets.cfg`의 `include_filter`에 등록한다.

## 프로젝트 자체 제작 에셋

- 플라스크 카드 이미지: CHEMI-SET 프로젝트 전용 에셋
- 앱 아이콘 및 로고: CHEMI-SET 프로젝트 전용 에셋
- UI 레이아웃과 스타일 리소스: CHEMI-SET 프로젝트 전용 에셋

프로젝트 자체 제작 에셋을 외부 도구나 제3자 작업물로 교체할 경우 해당 출처와 이용 조건을 이 문서에 추가한다.
