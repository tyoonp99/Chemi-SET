# CHEMI-SET UI 가이드

> 문서 버전: 1.1
> 구조와 책임은 `PROJECT_RULES.md`를 따른다.

## 기본

- 기준 화면은 세로형 720×1280이다.
- 기본 폰트는 `Pretendard-Medium.ttf`, 기본 크기는 28 이상이다. 작은 보조 정보만 예외로 한다.
- 배경은 `#1a2436`, HUD는 `#151d2c`, 팝업 패널은 `#232f3e`를 사용한다.
- 메인 버튼은 `#48bdf5`와 검정 텍스트, 서브 버튼은 `#303e4d`와 흰색 텍스트를 사용한다.

## HUD

- HUD 높이는 112다.
- 점수·시간·설정은 세 영역으로 균형 있게 배치한다.
- 자유 실험에서는 같은 HUD를 합성·완료 누적 카운터로 사용한다.
- 설정 버튼은 64×64, 우측 정렬, 투명도 0.59를 사용한다.

## 팝업

- 전체 화면을 덮는 `ColorRect` 위에 중앙 `PanelContainer`를 배치한다.
- 일반 딤 오버레이는 검정 Alpha 150이다. 게임 보드가 보이면 안 되는 일시정지 화면은 불투명 검정을 허용한다.
- 패널은 `popup_panel_style.tres`를 사용하며, 모서리 반경 24와 좌우 30·상하 40 여백을 유지한다.
- 정지 중 조작하는 `PausePopup`은 `Process Mode = Always`여야 한다.

## 피드백과 리소스

- 고정 버튼·패널·카드 스킨은 `.tres`로 재사용한다.
- 동적 점수 피드백은 `LabelSettings` 리소스로 폰트, 색상, 외곽선을 관리한다.
- 정답 피드백은 밝은 색과 검정 8px 외곽선을 사용해 카드 위에서도 읽혀야 한다.
- 중요한 상호작용에는 짧은 팝·페이드·흔들림을 사용하되, 레이아웃 위치를 영구적으로 변경하지 않는다.
